# Reflexão Final

1. **Qual a importância do Git para desenvolvimento de software?**  
O Git é importante porque permite o controle de versões do código, possibilitando acompanhar mudanças, recuperar versões anteriores e colaborar de forma organizada
 no desenvolvimento de software.

2. **Como o uso de branches pode ajudar no trabalho em equipe?**  
O uso de branches ajuda cada desenvolvedor a trabalhar em novas funcionalidades ou correções sem interferir diretamente no código principal, evitando conflitos
 e facilitando a integração posterior.

3. **Por que é importante escrever mensagens de commit claras?**  
Mensagens de commit claras ajudam a entender rapidamente o que foi alterado em cada versão do código, facilitando a comunicação entre a equipe e a manutenção futura
 do projeto.

4. **Quando você usaria o arquivo .gitignore?**  
O arquivo `.gitignore` é usado para indicar quais arquivos ou pastas não devem ser enviados ao repositório, como arquivos temporários, de configuração pessoal ou
 dependências que podem ser instaladas novamente.

5. **Como o histórico de commits do seu repositório demonstra seu aprendizado?**  
O histórico de commits demonstra a evolução do meu aprendizado, mostrando cada etapa concluída, desde a configuração inicial, criação de branches, resolução
 de conflitos, até a documentação final do projeto.
